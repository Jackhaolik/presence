# PRÉSENCE — V2

Site statique multi-pages prêt à tester et à mettre en ligne.

Fichiers :
- index.html
- module-1.html
- module-2.html
- module-3.html
- pratiques.html
- style.css
- script.js

Fonctions :
- navigation entre les pages
- exercices interactifs
- minuteurs
- respiration animée 5/5
- notes sauvegardées localement dans le navigateur
- scan corporel interactif
- vidéo YouTube officielle Wim Hof intégrée
- liens vers les ressources officielles

Le site n'utilise aucun framework et peut être publié sur GitHub Pages, Netlify ou un autre hébergeur statique.

À personnaliser ensuite :
- nom définitif
- logo
- photos
- identité sonore
- textes pédagogiques
- audios guidés originaux
- formulaire de contact / newsletter
- espace membre si nécessaire
